v0.11 검증 기록 — 2026-10-09

변경: RUN_PATCH.bat 한 번으로 ISO 준비와 기존 Xenia 프로필 도전 과제 설명 갱신을 연결했습니다.
번역 데이터·폰트·UI·실행파일 차분 및 GPD 문자열 변환 코드는 v0.10과 바이트 단위로 같습니다.
도전 과제 50개 제목·50개 설명 번역을 포함한 통합판입니다. 일반 대사와 신발자국 분석 대사는 변경하지 않았습니다.

시험한 주요 동작
- 원본 ISO 선택 → 한글 ISO 생성 → 활성 프로필 두 개의 설명 갱신까지 하나의 진입점에서 완료.
- 생성 ISO 전체 크기·수정 대상 해시 검사. 수정 범위 밖 전체 바이트와 원본 ISO 보존 확인.
- 도전 과제 ID·점수·획득 플래그·시각·기타 프로필 항목 보존과 백업 원본 일치 확인.
- 기존 v0.10/0.11 데이터의 ISO를 그대로 재사용하며 파일 전체 해시가 바뀌지 않음.
- 이미 한글인 프로필 재실행 시 수정·중복 백업 없음.
- 지원하지 않는 프로필 및 잘못된 ISO는 파일 변경 전에 거부.
- 프로필 0개이면 기본 중단. 신규 환경으로 명시한 경우만 진행하며 설명 갱신 완료로 표시하지 않음.
- 선택한 content 안에서도 활성 프로필 경로만 처리하고 별도 백업 폴더는 무시.
- 두 번째 프로필 교체 실패를 주입해 첫 번째 프로필의 원본 복구 확인.
- 사전 검사 이후 프로필이 바뀌면 다른 프로필까지 수정하기 전에 중단, 새 외부 기록 보존.
- 기본·별도 content_root·storage_root 경로 및 따옴표 표현 검사. 설정이 충돌하면 직접 content 선택을 요구.
- 최종 ZIP 무결성 및 파일별 SHA-256 확인. 실행용 BAT는 RUN_PATCH.bat 하나입니다.

시험 자료: 실제 제공된 원본 default.xex와 Layer0 첫 8MiB, 나머지는 전체 크기의 합성 ISO.
프로필 시험 자료: 공식 Xenia 구조에 맞춘 합성 GPD. 실제 사용자 프로필은 제공받지 않았습니다.
환경: PowerShell 7.4.6 / Linux. Windows 선택 창·실제 게임 실행 및 화면 표시·전체 완주는 미확인입니다.
따라서 데이터 검증을 모든 화면 번역 완료나 모든 환경의 무튕김 보장으로 해석하면 안 됩니다.
