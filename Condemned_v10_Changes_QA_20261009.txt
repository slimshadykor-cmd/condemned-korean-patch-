컨뎀드 한글 패치 v0.10 검증 기록 (2026-10-09)

수정 계기
v0.9 사용자 화면에서 도전 과제 목록은 한글이지만 오른쪽 제목·설명이 영어인 누락을 확인했습니다.
일반 문자열 DB·UI 외에 default.xex 내 XDBF 도전 과제 메타데이터가 별도로 사용되었습니다.
v0.9의 검수 범위가 이 저장 위치를 포함하지 못했습니다.

이번 수정
- 도전 과제 50개의 제목 50개와 설명 50개, 총 100개 문자열 번역.
- 제1장 새 수집 동상 설명: 와이즈먼 사무실 건물에서 죽은 새를 찾았습니다.
- 일반 대사·UI·폰트·신발자국 분석 대사는 v0.9 그대로입니다.
- original default.xex를 대상으로 하는 XOR 차분만 배포합니다. 원본 실행파일은 포함하지 않습니다.
- 실행파일 내 도전 과제 문자열 표와 그 위치·크기 정보가 바뀝니다. 게임 코드 바이트는 보존합니다.
- 기존 Xenia Canary 프로필의 영어 설명은 GPD 보조 도구로 제목·설명만 교체할 수 있습니다.

검증한 내용
1. 수정 XEX를 다시 복호화·분해해 XDBF 전체 항목의 범위·겹침을 검사했습니다.
2. 50개 도전 과제의 제목·설명 참조 100개가 번역문과 일치합니다. 기존 폰트에 필요한 글자 누락은 0개입니다.
3. 50개 도전 과제 ID·이미지 ID·점수·조건 플래그, 이미지 및 다른 언어 표가 원본과 일치합니다.
4. XDBF 밖 실행 이미지 바이트 및 기존 데이터가 동일합니다. 새 표는 확인한 기존 0 패딩 범위에 배치했습니다.
5. ISO 설치기를 실제 PowerShell/C# 런타임에서 실행했습니다. 원본 보존, 전체 출력 해시, 수정 범위 밖 바이트 일치, 잘못된 입력·손상된 차분의 거부를 확인했습니다.
6. 폴더판 v0.9 설치 → v0.10 업그레이드 → 원본 복원을 실제 실행했습니다. Layer0.Arch00와 default.xex가 원본 해시로 복원됩니다. 설치 후 변경된 실행파일은 복원 전에 거부합니다.
7. GPD 도구를 잠금·획득 상태가 섞인 50개 항목과 다른 프로필 데이터가 있는 시험 파일에 실행했습니다. 획득 플래그·시각·점수·기타 항목을 보존합니다. 한글 적용 후 새로 획득한 기록도 영어 설명 복원 시 유지합니다. 지원하지 않는 문자열은 수정하지 않고 거부합니다.
8. 최종 ZIP 파일 무결성 및 포함 파일별 SHA-256을 확인했습니다.

시험 환경 및 한계
PowerShell 7.4.6 / Linux. 사용자가 제공한 실제 Layer0 앞 8MiB와 원본 default.xex를 사용했습니다.
전체 크기의 합성 ISO·아카이브와 공식 Xenia 구조에 맞춘 합성 GPD로 설치·복원을 시험했습니다.
원본 전체 ISO 부팅, 사용자의 실제 GPD, Windows 선택 창, 게임 내 한글 표시·줄바꿈·엔딩까지 완주는 아직 확인하지 않았습니다.
데이터 검증은 모든 환경에서의 무튕김 또는 모든 화면의 번역 완료를 의미하지 않습니다.
XEX 서명 검증을 요구하는 실기 환경은 지원·검증 대상이 아닙니다. Xenia용입니다.
작업 중 전원 차단 등으로 두 파일 교체가 중단되면 백업을 보존한 채 오류 내용과 폴더 상태를 제보하세요.
source에 포함된 v0.9 이하 기록은 과거 버전의 기록입니다.
