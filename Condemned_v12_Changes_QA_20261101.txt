컨뎀드 v1.2 검수 기록 — 2026-11-01

변경 범위
- 게임 문자열 3,012개 중 승인된 조작 안내 18개 슬롯만 변경. 이 슬롯을 참조하는 힌트 키는 20개입니다.
- 각 문구에 원본의 입력 코드(action, flashlight, tools, fire, ammocheck, togglemelee, sprint, taser, kick, block, pause, aim, move)를 그대로 복원.
- 설명은 한글로 유지. 일반 도끼 안내와 신발자국 분석 대사를 포함한 나머지 문자열은 바이트 단위로 보존.
- 4,976개 내부 키·참조, 모든 문자열 시작 위치·종결 위치·슬롯 길이를 v1.1 그대로 보존.
- 게임 전체 원본 문자열의 입력/페이지/시간 코드와 새 번역의 코드 목록을 슬롯별 대조하여 일치 확인.
- 압축 방식을 조정하여 기존 문자열 저장 공간 안에 수용. 1,318개 리소스의 위치가 모두 v1.1과 동일.
- 메인화면의 크레딧 문자열에만 '  v1.2'를 추가. frontEndMenu.xur와 영어/한국어 frontEndMenu.xus에서 같은 문구를 갱신.
- XUR의 화면 구성·좌표·색상·폰트 크기 등 DATA/VECT/QUAT/DBUG 섹션 보존. 464개 UI 리소스 중 나머지 461개는 바이트 단위로 동일.
- 크레딧은 기존 26포인트/360픽셀 폭을 유지. 실제 폰트 메트릭 계산상 새 문구의 폭 약 225픽셀로 영역 안에 들어감.
- Layer0 첫 8MiB에서 변경 허용 범위는 공용/영어 문자열과 UI 압축 데이터 및 해당 디렉터리 크기 항목뿐.
- 기존 폰트·XEX 도전 과제 차분·도전 과제 번역·프로필 처리 코드는 v1.1과 완전히 동일.
- Xenia 실행파일/설정/HDD명은 변경하지 않음.

패치 프로그램 변경
- v1.2 표기와 출력 이름 갱신.
- 원본 설치와 해시가 일치하는 v1.1(구 v0.10/0.11 데이터) 갱신을 지원. 입력 ISO는 읽기 전용으로 열고 별도 ISO 생성.
- 기존 v1.2 ISO는 재생성 없이 재사용. 같은 출력 이름이 있으면 덮어쓰기 거부.
- RUN_PATCH.bat 단일 진입점과 기존 도전 과제 처리 흐름 유지.

실행 시험
- 실제 원본 실행파일·아카이브 앞 8MiB를 넣은 합성 ISO의 원본→v1.2, v1.1→v1.2 적용.
- 두 경로의 결과 ISO 전체 SHA-256 일치, 원본 보존, 수정 범위 밖 바이트 일치.
- v1.1 갱신에서는 실행파일 전체가 그대로이며 힌트 문자열과 크레딧 버전 표시만 달라짐.
- 50개 도전 과제의 혼합 획득 상태·점수·시각이 있는 합성 프로필로 기존 통합 실행 확인.
- 이미 한글인 프로필은 변경·추가 백업 없음. v1.2 재실행은 ISO도 변경하지 않음.
- 잘못된 실행파일/아카이브 조합, 변조된 기존 ISO, 손상된 패치 데이터, 같은 경로/기존 출력 덮어쓰기를 변경 전에 거부.

한계
시험 환경은 PowerShell 7.4.6/Linux입니다. 합성 ISO는 설치 검증용으로 게임 전체 데이터가 아닙니다.
Windows 파일 선택 창, 실제 v1.2의 버튼 그림·메인화면 버전 표시 및 게임 전체 완주는 아직 확인하지 않았습니다.
따라서 버튼 코드 복원 완료와 실제 화면 표시 확인을 구분합니다. 실제 게임 화면 확인은 필요합니다.
