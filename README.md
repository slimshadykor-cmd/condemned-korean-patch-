# Condemned: Criminal Origins 한글 패치

**한글화: 슬림쉐이디**

**테이저·손전등·공격·방어 등 조작 안내 18개 문구의 원본 버튼 표시 코드를 복원했습니다. 설명은 한글로 유지합니다.**

## 다운로드

**[ISO용 v1.2 다운로드](https://github.com/slimshadykor-cmd/condemned-korean-patch-/raw/refs/heads/main/Condemned_Korean_ISO_v12.zip)** · 4,264,272바이트

기존 번역과 도전 과제 50개의 제목·설명을 포함한 통합판입니다. 이전 패치를 먼저 적용할 필요가 없습니다.

## v1.2 변경 사항

- 버튼 안내를 '테이저 버튼' 같은 글자로 바꾸면서 빠졌던 입력 코드를 18개 문구에 복원했습니다.
- 게임이 원래 버튼 표시를 넣는 부분을 한글 문장 안에 유지했습니다. 버튼이 없는 일반 목표 안내는 그대로입니다.
- 메인화면 크레딧을 **한글화: 슬림쉐이디  v1.2**로 표시합니다.
- 다른 번역·폰트·UI 구성·실행파일 차분·도전 과제·신발자국 분석 대사는 v1.1과 같습니다.
- 원본 ISO와 기존 v1.1 한글 ISO에서 모두 v1.2 ISO를 만들 수 있습니다.

**버튼 코드와 패치 결과는 데이터 검사를 마쳤습니다. 실제 v1.2 게임 화면에서 버튼 그림이 표시되는지는 아직 확인이 필요합니다.**

## 설치

1. ZIP 전체를 압축 해제합니다. `data` 폴더도 함께 유지하세요.
2. 게임과 Xenia를 종료하고 **RUN_PATCH.bat** 하나를 실행합니다.
3. **지원되는 원본 ISO 또는 기존 v1.1 한글 ISO**를 선택합니다.
4. 이어지는 창에서 사용 중인 **Xenia 폴더 또는 실제 content 폴더**를 선택합니다.
5. 완료 메시지에 표시된 ISO를 Xenia에서 실행합니다. 콘솔 언어는 English 또는 Korean입니다.

입력 ISO와 같은 폴더에 `이름_Korean_v12.iso`를 새로 만듭니다. 예를 들어 `Condemned_Korean_v11.iso`를 선택하면 `Condemned_Korean_v12.iso`가 생성됩니다. 입력 ISO는 보존하며 새 ISO 한 개 크기 이상의 공간이 필요합니다.

같은 이름의 출력 파일이 있으면 덮어쓰지 않습니다. 이미 v1.2인 ISO를 선택하면 해시 확인 후 재사용합니다.

v1.1은 구 v0.11과 같은 배포본입니다. 같은 게임 데이터의 v0.10도 해시가 일치하면 갱신됩니다. v0.9 이하 또는 다른 수정이 들어간 ISO는 지원되는 원본 ISO에서 새로 적용하세요.

## 기존 도전 과제와 저장 기록

ISO와 기존 도전 과제 설명을 한 번 실행으로 처리합니다. 보조 실행 파일을 따로 실행할 필요가 없습니다. 이미 한글인 프로필은 수정하거나 추가 백업하지 않습니다.

영어 설명이 있는 프로필은 기존 방식대로 제목·설명만 갱신하며 획득 여부·시각·점수와 다른 항목은 보존하고 자동 백업합니다. 이미 게임을 실행했는데 기록이 없다고 나오면 **아니요**를 눌러 실제 `content` 폴더를 다시 선택하세요. 처음 실행하거나 GPD 기록을 쓰지 않는 구버전인 경우에만 기존 기록 없이 진행합니다.

프로필 처리에 실패했다면 오류를 해결하고 같은 `RUN_PATCH.bat`로 준비된 ISO를 선택해 다시 진행하세요. 세이브나 프로필을 삭제할 필요가 없습니다. Xenia 실행파일·설정·저장 장치 이름은 이 패치에서 변경하지 않습니다.

## 검수 범위

게임 문자열은 정확히 18개 슬롯만 바뀌었으며 4,976개 내부 키, 모든 문자열 위치와 1,318개 리소스 위치를 보존했습니다. UI는 크레딧 버전 문구만 바꾸고 화면 구성과 좌표를 유지했습니다. 나머지 폰트·UI 리소스·실행파일 차분은 v1.1과 바이트 단위로 같습니다.

실제 원본 실행파일과 아카이브 앞 8MiB를 넣은 합성 ISO로 원본 설치·v1.1 갱신·재실행을 PowerShell 7.4.6/Linux에서 시험했습니다. 두 설치 경로의 결과 ISO 전체 해시가 같고, 입력 ISO 보존·프로필 획득 기록 보존·오류 거부를 확인했습니다.
