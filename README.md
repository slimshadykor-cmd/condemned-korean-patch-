# Condemned: Criminal Origins 한글 패치

**한글화: 슬림쉐이디**  
Xbox 360판 / Xenia용 · **v1.1 한 번 실행하는 ISO 통합 패치** · 버전 표기 정리: 2026-10-15

**v1.1은 기존 v0.11의 배포 버전명만 정리한 동일한 파일입니다.** 패치 동작·번역 데이터·ZIP 내용은 변경하지 않았으며, 기존 v0.11 사용자는 다시 패치할 필요가 없습니다. 기존 링크와 파일명 `Condemned_Korean_ISO_v11.zip`을 유지합니다. ZIP 내부 안내나 프로그램에 남아 있는 v0.11 표기는 같은 배포본을 뜻합니다.

이전 번역과 수정 사항을 포함한 통합판입니다. 도전 과제 50개의 제목·설명 100개 번역도 포함합니다. 번역 데이터는 v0.10과 같으며, 기존 v0.11(현재 배포명 v1.1)에서 설치 과정을 통합했습니다.

## 설치

1. ZIP 전체를 압축 해제합니다. `data` 폴더도 함께 유지하세요.
2. 게임과 Xenia를 완전히 종료하고 **RUN_PATCH.bat**를 실행합니다.
3. **원본 ISO 또는 이미 만든 v0.10 / v0.11(현재 v1.1) 한글 ISO**를 선택합니다.
4. 이어서 나오는 창에서 **현재 사용하는 Xenia 실행파일이 있는 폴더 또는 실제 기록이 저장된 `content` 폴더**를 선택합니다. ISO 보관 폴더와 Xenia 기록 폴더는 서로 다를 수 있습니다.
5. ISO와 도전 과제 설명 처리가 모두 완료됐다는 메시지를 확인합니다.
6. 화면에 안내된 ISO를 Xenia에서 실행합니다. 콘솔 언어는 English 또는 Korean으로 설정합니다.

**이미 v0.10 ISO가 있으면 그 파일을 선택하시면 됩니다.** 해시를 확인한 뒤 ISO를 재생성하지 않고 기존 프로필 설명을 갱신합니다. v0.9 이하 ISO는 원본에서 새로 만들어야 합니다.

원본 ISO는 보존됩니다. 새 ISO 생성 시 ISO 한 개 크기 이상의 여유 공간이 필요합니다.

## 패치된 ISO 저장 위치

- **원본 ISO를 선택한 경우:** 원본과 같은 폴더에 `원래파일명_Korean_v11.iso`가 생성됩니다.
- **이미 v0.10 / v0.11(현재 v1.1) 패치된 ISO를 선택한 경우:** 새 ISO를 만들지 않고 선택한 파일을 그대로 사용합니다. 기존 도전 과제 설명은 선택한 Xenia 기록에 적용됩니다.
- 완료 창의 **`실행할 ISO:`** 옆에 표시되는 경로를 확인하세요. 패치 폴더의 `patch_result_날짜.json`에도 실행할 ISO 경로가 기록됩니다.

## 기존 기록을 찾지 못했다면

이미 게임에서 영어 도전 과제 설명을 보셨다면, 기록 없음 안내에서 **아니요**를 눌러 실제 사용하는 `content` 폴더를 다시 선택하세요. 처음 실행하거나 GPD를 사용하지 않는 구버전인 경우에만 기존 기록 없이 진행합니다.

패치가 기록을 찾지 못한 상태를 설명 갱신 완료로 표시하지 않습니다. Xenia를 여러 위치에 설치했거나 저장 경로를 바꿨다면 현재 게임에서 쓰는 폴더를 선택해야 합니다.

## 기록 보존·재시도

선택한 content 폴더의 활성 프로필에서 컨뎀드의 제목·설명만 교체하고, 획득 여부·시각·점수와 다른 항목을 보존합니다. 실제 변경 전 자동 백업을 남깁니다. 이미 한글이면 다시 수정하지 않습니다.

프로필 처리에 실패하면 전체 완료로 표시하지 않습니다. ISO가 준비된 뒤 실패한 경우, 원인을 해결하고 **같은 RUN_PATCH.bat**를 실행해 준비된 ISO를 선택하면 이어서 처리할 수 있습니다. 세이브나 프로필을 삭제할 필요가 없습니다.

통합 설치, 기존 ISO 재사용, 도전 과제 기록 보존, 실패 시 복구에 대한 데이터 검사를 완료했습니다.

2026-10-09 사용자 테스트에서 실제 사용하는 기록 폴더를 선택한 뒤 패치를 진행했고, 앞서 영어로 남아 있던 도전 과제 문구가 한글로 표시되는 것을 확인했습니다. 이 확인은 해당 환경과 확인한 화면에 한정됩니다.

**엔딩까지 전체 플레이 검수는 완료하지 않았습니다.** 데이터 검사가 게임 전체의 미번역 0개나 모든 환경의 무튕김을 보장하지는 않습니다. 상세 데이터 검수와 추가 사용자 확인은 [검수 기록](Condemned_v11_Changes_QA_20261009.txt)을 참고하세요. ZIP 안의 `QA_KR.txt`는 사용자 확인 전의 데이터 검수 기록입니다.
